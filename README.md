# Portfolio Web - Gabriel Polo Merlo

Portfolio personal desarrollado como página web estática para presentar mi perfil profesional, formación, experiencia y conocimientos técnicos en administración de sistemas, redes, virtualización y ciberseguridad.

## Vista previa

La web está publicada con GitHub Pages:

https://gabmerpol2005.github.io

## Contenido

* Perfil profesional
* Habilidades técnicas
* Tecnologías utilizadas
* Experiencia en prácticas
* Formación académica
* Información de contacto

## Tecnologías usadas

* HTML5
* CSS3
* Diseño responsive
* GitHub Pages

## Objetivo del proyecto

Este proyecto tiene como objetivo mostrar de forma clara y profesional mi perfil como Técnico Superior en Administración de Sistemas Informáticos en Red, destacando conocimientos en Linux, Proxmox, redes, virtualización, scripting y ciberseguridad.
